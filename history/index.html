How this is stored

Search history is kept in this browser's localStorage under the key gw-history, as a list of query, time, result count and duration. It holds the most recent 200 searches; older ones are dropped automatically. It is never uploaded, never sent with a search, and never included in a shared or custom index.

  • Delete all clears the list immediately. Deleting a single row removes just that search.
  • Stopping recording leaves existing entries alone; it only prevents new ones being added.
  • Clearing your browser's site data for Gateway also removes the history, along with preferences and the cached index.
  • Because the list is local, it does not follow you to another browser, device, or profile.

See the Privacy page for how Gateway handles data in general.
