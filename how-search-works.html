Gateway

How Search works

Gateway is a multi-source search engine that pulls results from several free APIs — no central index, no API keys required, and no tracking.

No index. No API key. No tracking.

Gateway does not maintain its own search index. Instead, it queries multiple independent sources at once, merges and deduplicates the results, and presents them in a clean Google-like interface.

There are no user accounts, no search history stored on servers, and no behavioural tracking. Your queries go directly to the underlying sources — Gateway never sees or stores them.

Sources

Each search fans out to the following sources in parallel:

Wikipedia

Top search results with full-text extracts, thumbnails, and direct article links via the MediaWiki API.

DuckDuckGo

Organic web results fetched through DuckDuckGo's HTML search endpoint — the same quality as Google or Bing without the tracking.

Wikimedia Commons

Free-license images with thumbnails and descriptions for the Images tab.

All queries are rate-limited with AbortController timeouts (3s for API sources, 4.5s for web) so slow providers never block the whole search. Results are cached in memory and localStorage for 10 minutes, making repeat searches instant.

Ranking & Boosting

Results are scored and sorted by relevance:

  • Domain boost — certain trusted sites get a higher base score
  • Keyword match — results matching more query terms rank higher
  • Exact phrase bonus — the exact query in the title or description adds extra weight
  • Secret list — searching "xpdevs" or "gateway" pins official XPDevs pages to the top with a score of 99,999

Safety & Filtering

Every result passes through a safety layer before it reaches you:

  • Domain blocklist — 25+ dangerous domains are removed (malware, phishing, shock sites, Tor gateways, URL shorteners)
  • Keyword filter — results containing dangerous keywords (malware, crack, warez, etc.) are blocked
  • Tracking removal — query parameters like utm_*, fbclid, ref are stripped from all result URLs

Answer Box

For factual queries, Gateway shows a Quick Answer box at the top of the All tab. It pulls a one-sentence extract from Wikipedia and links up to four diverse web sources alongside it, giving you both a direct answer and paths to explore deeper.

Dark Mode

Dark mode is stored in localStorage and applied before the page renders — no white flash. The toggle works instantly and persists across sessions.

Performance

Gateway is designed to be fast without a server:

  • All processing happens in your browser
  • Parallel requests to all sources at once
  • Smart payload limits (e.g. 5 Wikipedia articles instead of 15)
  • localStorage cache keeps previous results for instant recall

Open Source

Gateway is built by XPDevs. The full source is available on GitHub — you can inspect, fork, or self-host it.
