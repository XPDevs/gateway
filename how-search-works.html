Gateway

How Search works

Gateway searches a bundled local index — completely offline, no servers, no tracking.

Local index

Gateway ships with a comprehensive offline index of thousands of topics across science, history, technology, geography, arts, and more. The index is loaded directly into your browser on startup and stored in IndexedDB for instant access on subsequent visits. No network requests are made when you search.

Ranking

Results are scored and sorted by relevance:

  • Keyword match — results matching more query terms rank higher
  • Exact phrase bonus — the exact query in the title or description adds extra weight
  • Prefix boost — titles starting with the query get a significant score bump
  • Secret list — searching "xpdevs" or "gateway" pins official XPDevs pages to the top with a score of 99,999

Safety & Filtering

Every result passes through a safety layer before it reaches you:

  • Domain blocklist — 25+ dangerous domains are removed (malware, phishing, shock sites, Tor gateways, URL shorteners)
  • Keyword filter — results containing dangerous keywords (malware, crack, warez, etc.) are blocked
  • Tracking removal — query parameters like utm_*, fbclid, ref are stripped from all result URLs

Custom index

You can upload your own JSON index via Settings → Upload Index. The uploaded index replaces the built-in one and persists across page reloads in IndexedDB, allowing you to customise Gateway with your own data.

Dark Mode

Dark mode is stored in localStorage and applied before the page renders — no white flash. The toggle works instantly and persists across sessions.

Performance

Gateway is designed to be fast without a server:

  • All processing happens in your browser with zero network requests
  • Results are cached in memory for 10 minutes for instant repeat searches
  • IndexedDB persists the index across sessions without re-downloading

Open Source

Gateway is built by XPDevs. The full source is available on GitHub — you can inspect, fork, or self-host it.
