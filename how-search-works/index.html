Gateway

How Search works

Gateway combines a bundled local index with optional, sourced open-data discovery. It runs without a Gateway backend and does not use generative AI.

Local index

Gateway ships with a local index of thousands of Wikipedia articles and selected open-web entries. It is loaded directly into your browser and stored in IndexedDB. Local matching and ranking do not require a request; the current bundled index contains 10,523 entries.

Live discovery

For a search, Gateway can ask Wikipedia's public API for matching article extracts and current external links. Wikidata provides structured claims such as release dates, founders, headquarters, and official websites. These requests disclose the searched subject to the public API provider; no full history is sent.

Quick Wiki

Quick Wiki is deterministic, not generative. Gateway recognizes common question patterns, matches a Wikipedia article, reads a relevant Wikidata claim when one exists, and formats the value with its property identifier. If structured data is unavailable, it displays a direct extract and labels that fallback clearly.

Ranking

Results are scored and sorted by relevance:

  • Keyword match: results matching more query terms rank higher
  • Exact phrase bonus: the exact query in the title or description adds extra weight
  • Prefix boost: titles starting with the query get a significant score bump
  • Source signals: the best article, an official website from Wikidata, and cited non-Wikipedia links receive explicit source-aware scores
  • Deduplication: tracking parameters are removed and equivalent URLs are shown once

Safety & Filtering

Every result passes through a safety layer before it reaches you:

  • Domain blocklist: 25+ dangerous domains are removed (malware, phishing, shock sites, Tor gateways, URL shorteners)
  • Keyword filter: results containing dangerous keywords (malware, crack, warez, etc.) are blocked
  • Tracking removal: query parameters like utm_*, fbclid, ref are stripped from all result URLs

Custom index

You can upload your own JSON index via Settings -> Upload Index. The uploaded index replaces the built-in one and persists across page reloads in IndexedDB, allowing you to customise Gateway with your own data.

For a bounded, dependency-free crawl of public pages, use npm run build:web-index. It reads seeds.txt, follows links to the configured depth, respects robots.txt by default, and writes a merged JSON index without an AI model or search API.

Dark Mode

Dark mode is stored in localStorage and applied before the page renders, so there is no white flash. The toggle works instantly and persists across sessions.

Performance

Gateway is designed to be fast without a Gateway server:

  • Local matching and ranking happen in your browser
  • Public discovery requests are short-lived and independent of the bundled index
  • Search results and API responses are cached for ten minutes for repeat searches
  • IndexedDB persists the index across sessions without re-downloading unchanged data

Open Source

Gateway is built by XPDevs. The full source is available on GitHub. You can inspect, fork, or self-host it.
